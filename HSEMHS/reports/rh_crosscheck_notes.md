## Gate 2 RH row: pressure on 3 Bifrost columns (pass)

**Setup.** Each column goes to RH as a column-mass atmosphere, with m = colmass + m_top (m_top = P_top/g), the same T and nₑ, and the Wittmann abundances. RH's P = g·m is algebraic, so pressure can only differ through the height scale z(m), which RH builds by the trapezoid rule on dm/ρ.

| Variant | Result |
|---|---|
| RH on the native 177-level grid | 2–14 % in P at fixed height. RH's trapezoid costs ~0.4 % of each 20 km layer; this adds up to 5–13 km over 3.5 Mm. |
| RH given our n_H, same T(z) profile refined ×1/×4/×16/×64 | max \|ΔP/P\| = 1.3e-1 → 1.0e-2 → 1.3e-3 → **6.8e-4** (worst of 3 columns), about second order until the floor |
| RH computing its own n_H from P = g m, same refinement | plateaus at 2e-3 – 1.7e-2 |

The matched-EOS run converges onto the HSEMHS solution. The remaining 2–7e-4 floor matches HSEMHS's own RK4 tolerance (1e-6 in ln P per interval over 177 intervals).

The plateau when RH computes its own n_H is a real EOS difference: RH's MULTI-style n_H = (gm − nₑkT)/(Σ_A kT) ignores H₂. Wittmann includes H₂, which changes ρ by up to 1.1 % at 3500 K and 500 Pa, so the heights above that layer shift.

Spec Gate 2 says "matched-EOS LTE comparison", so the matched run is the gate number: **6.8e-4 ≤ 1e-3**.

## Gate 1 RH row: 500 nm background opacity (partial pass)

**Photospheric points (T ≤ 6000 K, z = 130–400 km):** |Δχ/χ| ≤ 2.3 %. Pass.

**Hotter points (7700–11500 K, z ≤ 75 km, below τ₅₀₀ = 1):** HSEMHS is 4.8–6.8 % above RH. The breakdown at 11 489 K, 3.9e4 Pa, in m⁻¹:

| Contribution | HSEMHS (Wittmann/ATLAS) | RH | HSEMHS/RH |
|---|---|---|---|
| H bound-free | 5.59e-3 | 4.71e-3 | 1.19 |
| H free-free | 0.98e-3 | 1.02e-3 | 0.96 |
| H⁻ (bf + ff) | 2.66e-3 | 2.98e-3 | 0.89 |
| H₂⁺ | 2.6e-4 | 1.4e-4 | 1.8 |
| total | 9.51e-3 | 8.87e-3 | 1.07 |

This is a difference between the opacity models, not an implementation error. The Julia port reproduces the Python Wittmann `cop` to 4e-16. Wittmann's `HOP` (ATLAS) treats hydrogen levels n ≤ 8 explicitly and merges higher levels up to the series limit, while RH uses its model atom's cross sections. Replacing RH's `H_6.atom` with `H_20.atom` barely changes the result (6.61 % vs 6.78 %). The H⁻ fits also differ by ~10 %.

These points sit below the photosphere (z ≤ 75 km). The spec's 5 % criterion holds for the photospheric points and fails for the hotter, deeper ones. Follow-up investigation (`reports/rh_opacity_investigation.md`): the H bf and H⁻ differences are two RH artifacts; with them removed, all 10 points agree within 4.3 %, and the remainder is H₂⁺ data (ATLAS vs Bates 1952).

## τ₅₀₀ comparison (diagnostic)

Below the top node, log τ₅₀₀(RH) − log τ₅₀₀(HSEMHS) has a median of +0.016 to +0.49 dex. The top closures differ: RH uses τ_top = χ₀m₀/ρ₀, HSEMHS uses χ₁H_χ. Off-photosphere opacities and RH's height scale also differ, so this is not gated.
